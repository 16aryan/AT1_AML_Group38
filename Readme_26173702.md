# AT1 Experiments — Pal Patel (26173702)

This file documents my individual contribution to the group's NBA career-longevity
prediction project. My work lives on the branch `26173702-AT1-experiments`, with my
best-performing approach (Experiment 4) merged into `main`.

## Overview

Four experiments were run, each testing a distinct, explicitly stated hypothesis,
using a consistent player-grouped train/validation/test split (70/15/15, seed=42)
across all four for fair comparison.

| Experiment | Approach | Hypothesis | Validation AUPRC | Test AUPRC | Outcome |
|---|---|---|---|---|---|
| 1 | Weighted ensemble (Logistic Regression + Random Forest + HistGradientBoosting) | A weighted ensemble of diverse models beats any single model | 0.498 | 0.511 | Confirmed |
| 2 | XGBoost imbalance-handling comparison (plain / scale_pos_weight / SMOTE) | Explicit class-imbalance handling improves XGBoost | 0.481 (plain, best variant) | 0.520 | Rejected — plain XGBoost won |
| 3 | KNN and SVM (RBF) | Distance/margin-based models underperform tree-based models | 0.481 (SVM) / 0.448 (KNN) | 0.489 / 0.425 | Partially confirmed — KNN underperformed as expected, SVM did not |
| 4 | Five-model weighted ensemble (LR + RF + HistGBM + XGBoost + SVM) | Combining the strongest models from Experiments 1–3 beats the original 3-model ensemble | 0.515 | **0.525** | Confirmed — best result overall |

**Recommended model: Experiment 4** (five-model weighted ensemble), test AUPRC 0.525.
Final ensemble weights: SVM 38.3%, Logistic Regression 23.4%, XGBoost 18.7%,
Random Forest 17.7%, HistGradientBoosting 1.9%.

All four notebooks are self-contained: each independently loads the raw data, builds
its own feature set, performs its own train/val/test split, trains its models, and
reports its own results with justification. Experiment 4 builds on findings from the
first three, but does not depend on them being run first — it retrains all five base
models from scratch.

## Reproducing these notebooks

1. Download `train.csv`, `test.csv`, `sample_submission.csv`, and `metadata.csv` from
   the Kaggle competition page (not included in this repo — see the group README for
   why).
2. Place them in `data/raw/` at the repo root.
3. Open any notebook from within `notebooks/` and run all cells top to bottom. Each
   notebook reads data via `data_raw_path = '../data/raw'`, so it must be run with
   `notebooks/` as the working directory (this is automatic if the notebook file
   itself is opened from that folder).
4. If running in Google Colab without cloning the full repo structure, clone the repo
   first (`!git clone ...`) and `cd` into `notebooks/` before running, so the relative
   path resolves correctly. See inline comments in each notebook for details.

## Known limitations (documented honestly, not hidden)

- The `college_seasons_played` engineered feature has a look-ahead risk: it is
  calculated from a player's full season history rather than only seasons prior to
  the prediction point, and should be corrected before any real deployment.
- The SVM component of Experiment 3/4 was trained on a 6,000-row subsample of the
  training data due to compute cost; its true performance on the full dataset is
  untested and may differ.
- `Rec Rank` (recruiting rank) and several shot-profiling columns were excluded due
  to high missingness (~69% and 24–63% respectively) rather than imputed, since their
  missingness is plausibly informative; this is a candidate for future feature work.
